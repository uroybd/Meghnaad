# Using Meghnaad

This guide is for every flavour. The web app, the Android app and the terminal app have the same pages, console, task
commands, boards, kanbans and keys, so a chapter here holds for all three; where one of them differs, the chapter says
so. What only one of them has is in its own chapter at the end. Behaviour follows Taskwarrior **3.6.0**; how the engine
works is in [Architecture](architecture.md), and every supported `taskrc` setting is in
[taskrc support](taskrc-support.md).
